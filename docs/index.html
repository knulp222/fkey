Comment ça marche

FKey reste discret et agit directement dans le champ où vous écrivez.

1

Sélectionnez un texte

Un mot, une phrase, un mail entier — dans Word, Outlook, Teams, votre navigateur…

2

Lancez FKey

Utilisez le raccourci de correction ou donnez votre propre instruction. Les touches disponibles sont indiquées plus bas pour chaque version.

3

Continuez à écrire

Le résultat remplace le texte dans le même champ. Si rien n'est sélectionné, FKey peut corriger tout le champ.

Traitement local

La correction et la génération se font sur votre ordinateur, sans envoyer vos textes à un service externe.

Télécharger FKey

Choisissez la version adaptée à votre ordinateur. Dans les deux cas, vos textes sont traités localement.

Windows v1.0.1

Application portable avec un modèle local à installer au premier lancement.

  • Windows 10 ou 11, 64 bits
  • Raccourcis : F2, F3, F4 et F6
  • Décompressez l'archive, puis lancez FKey.exe
Télécharger pour Windows
Un téléchargement initial du modèle est nécessaire.

Mac v1.3 test

Application utilisant le modèle Apple Intelligence disponible sur votre Mac.

  • Mac avec puce Apple · macOS 26 ou plus récent
  • Raccourcis : ⌃⌥K pour corriger, ⌃⌥G pour une instruction
  • Glissez FKey dans Applications, puis autorisez Accessibilité
Télécharger pour Mac
Apple Intelligence doit être activé. Version de test non notarisée.

Questions fréquentes

Quelle configuration faut-il ?

Sur Windows : Windows 10 ou 11 en 64 bits, 8 Go de mémoire vive recommandés (le modèle en occupe environ 2,7 Go) et 4 Go d'espace disque. Sur Mac : puce Apple, macOS 26 ou plus récent et Apple Intelligence activé.

Ça marche vraiment sans internet ?

Oui, une fois le modèle prêt sur votre ordinateur. Sur Windows, FKey le télécharge au premier lancement. Sur Mac, activez Apple Intelligence dans les réglages du système. La correction et la génération n'envoient ensuite pas vos textes à un serveur.

Windows affiche un avertissement au lancement

FKey n'est pas encore signé numériquement. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ». Le projet GitHub est public.

macOS bloque l'ouverture de FKey

La version Mac de test n'est pas encore signée et notarisée avec un compte Apple Developer. Après avoir glissé FKey dans Applications, essayez de l'ouvrir, puis utilisez « Ouvrir quand même » dans Réglages Système → Confidentialité et sécurité. Autorisez aussi l'accès Accessibilité demandé au premier lancement.

Comment désinstaller ?

Quittez FKey, puis supprimez l'application. Sur Windows, supprimez le dossier décompressé ; sur Mac, retirez FKey d'Applications. Si le démarrage automatique était activé, désactivez-le d'abord dans les réglages de FKey.
